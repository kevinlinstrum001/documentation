MEADOWS HOUSEKEEPING SITE ICONS

Place all files in the same folder as the HTML page, then paste the contents of
head-icon-links.html inside the page's <head> element.

Files:
- favicon.ico: browser tabs and legacy browser support
- favicon-16x16.png: very small browser icon
- favicon-32x32.png: standard browser tab icon
- apple-touch-icon.png: iPhone/iPad home-screen icon
- icon-192.png: Android/PWA icon
- icon-512.png: large Android/PWA icon
- site.webmanifest: mobile/PWA icon metadata
- head-icon-links.html: tags to paste into <head>

No CSS is required for favicons or mobile home-screen icons. Browsers read these
<link> and <meta> tags directly.
