Meadows Housekeeping System

Work completed and current capabilities for supervisor review

Overview: A functional housekeeping communication website is now in place. The calendar, employee roster information, housekeeping issue form, QR resources, and visual navigation have been brought together into one system that can be accessed from a phone or computer.

Work Completed

1. Calendar structure corrected

  • Philip was removed from the personal calendar and placed on the work calendar.
  • Work scheduling is now separated from the personal calendar, reducing clutter.
  • The work calendar was verified to contain events through Christmas.

2. Meadows Housekeeping website created

  • A central website was created for housekeeping communication and reference material.
  • The homepage now provides direct access to the system's primary functions.
  • The site is designed to work well on both mobile devices and computers.

3. Work calendar embedded

  • The supervisor can scroll through days and months directly from the website.
  • Calendar events can be opened to view additional details.
  • Each morning event contains the roster of employees expected to be present.
  • Calendar information is visible through the site without requiring the supervisor to search through separate files.
  • Events can also be copied to another calendar.

4. Housekeeping issue form embedded

  • The Google issue form is available directly from its website page.
  • The form provides a consistent method for reporting housekeeping issues and requests.
  • The form will be reviewed with the supervisor during tomorrow's meeting.

5. Homepage navigation images created

  • Calendar
  • Housekeeping Issue Form
  • Roster

These images serve as clear visual shortcuts to the main functions of the site.

6. Images and QR resource page created

  • A separate page was added to retain QR code images and other reusable materials.
  • The supervisor can access, print, or reuse these materials as needed.
  • The page can later hold additional posters, reference graphics, and printable cards.

7. QR access established

  • QR codes provide quick access to the website and forms.
  • These codes can be printed and posted in the office or other useful locations.
  • More decorative or compact versions can be created later for permanent display.

Current Supervisor Capabilities

View future staffing Review calendar events and staffing information through Christmas.
Review daily rosters Open morning events to see which employees are expected to be present.
Submit housekeeping issues Open the embedded Google form directly from the website.
Use QR access Reach the site or forms quickly from printed QR codes.
Access reference material Retrieve saved QR images and other supervisor resources from the Images page.
Use one central interface Calendar, roster, forms, and reference materials are connected in one location.
